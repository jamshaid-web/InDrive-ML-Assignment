Project Title: InDrive Ride Acceptance Prediction
Project Overview
This project performs a complete Machine Learning Life Cycle on a specific dataset related to the InDrive service in Pakistan. The goal is to predict whether a driver will accept or reject a ride request based on several factors like fare, distance, and timing.

Problem Statement
In ride-hailing apps like InDrive, passengers offer a fare, and drivers decide whether to accept it. This project uses Machine Learning to understand the patterns behind these decisions—specifically focusing on how distance and offered fares affect the acceptance rate in the local Pakistani market.

Machine Learning Life Cycle Steps Performed:
Data Collection: Created a custom dataset representing real-world InDrive scenarios (Distance in KM, Offered Fare in PKR, and Peak Hour status).

Data Pre-processing: Handled features and targets, and split the data for training and testing.

Model Selection: Implemented two different classification models:

Random Forest Classifier

Logistic Regression

Model Training: Trained the models using the training data subset.

Evaluation: Compared the performance of both models using the Accuracy Score to determine which algorithm predicts driver behavior more accurately.
